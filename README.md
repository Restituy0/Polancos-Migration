# Polanco's Migracion – Sitio Web Institucional

Sitio web oficial de Polanco's Migracion, desarrollado y mantenido por mi en la empresa. El sitio presenta los servicios de la compañía y facilita el contacto con clientes.

## Descripción

Página web informativa que representa la presencia digital actual de Polanco's Migracion. Desarrollada para dar a conocer a su representante, facilitando el acceso a los usuarios de contactarla.

## Tecnologías utilizadas

- *HTML5* – Estructura semántica
- *CSS3* – Estilos y diseño visual
- *JavaScript* – Interactividad de la interfaz

## Estructura del proyecto

```
ErsVisa/
├── css/          # Hojas de estilo
├── img/          # Recursos gráficos
├── js/           # Scripts de interactividad
├── pages/     # Secciones modulares del sitio
└── index.html    # Página principal
```

## Características

- Sitio actualmente en producción para uso real de la empresa
- Diseño responsivo
- Integración de enlace directo a WhatsApp para atención al cliente
- Estructura modular por secciones
